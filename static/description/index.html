Gestão de Inventário com Código de Barras

Acelere as operações de armazém na versão Community!

O DL Stock Barcode traz a agilidade necessária para o chão de fábrica e armazéns. Com uma interface moderna desenvolvida em OWL (Odoo Web Library), permite pesquisar transferências, adicionar quantidades e validar guias usando apenas o leitor de códigos de barras.

Principais Benefícios

Aumento de Produtividade

Reduza o tempo gasto com preenchimento manual de dados. Faça scan aos produtos e as quantidades somam automaticamente.

Feedback Sonoro (Beep)

O sistema emite alertas sonoros agudos para sucesso e graves para erro, permitindo ao operador trabalhar sem olhar para a tela.

Comandos Rápidos

Imprima códigos de ação como O-CMD-VALIDATE. Leia esse código e valide a guia instantaneamente.

Como Funciona?

  • 1. Ecrã Ativo: A janela tem de ser a janela principal do computador para ler. Se clicar noutra aba, não fará a leitura.
  • 2. Abertura Rápida: Faça o scan do número de uma guia (ex: WH/IN/0001) para que o sistema a abra imediatamente.
  • 3. Scan de Produto: Cada scan num código de barras de produto adiciona +1 na quantidade da transferência.
  • 4. Etiquetas Ocultas: Abra o ficheiro etiquetas_comandos.html incluído neste módulo no seu browser e imprima os códigos mágicos de validação ou cancelamento para colocar no armazém.
