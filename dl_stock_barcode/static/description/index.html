⚡ Hands-Free Operational Command Barcodes

The module includes ready-to-print barcode action labels (accessible via etiquetas_comandos.html). Affix these barcodes near warehouse terminals to allow operators to complete full transfer cycles without a mouse or keyboard.

O-CMD-VALIDATE

Validate Transfer: Finalizes stock verification and validates inventory movements automatically.

O-CMD-CANCEL

Cancel Operation: Aborts current picking session and resets terminal state.

O-CMD-PRINT

Print Delivery Slip: Triggers instantaneous generation and printing of the delivery slip PDF.

❓ Frequently Asked Questions (FAQ)

Straightforward answers to key hardware, configuration, and licensing questions.

Does this module require Odoo Enterprise?

No! The primary advantage of dl_stock_barcode is bringing a powerful, dedicated barcode scanning experience to Odoo Community Edition, eliminating the requirement for an expensive Enterprise subscription while also working seamlessly on Enterprise.

Which barcode scanner models are compatible?

Any standard barcode reader that functions as a Human Interface Device (HID keyboard wedge), including wireless Bluetooth scanners, USB laser scanners, and mobile rugged terminals from Zebra, Honeywell, Datalogic, or Newland.

How does audio feedback work without extra hardware?

The module leverages the standard HTML5 Web Audio API directly in your web browser. When an operator scans an item, the browser generates real-time audio frequencies through the terminal's built-in speaker.

How do action commands work?

Open etiquetas_comandos.html included in the module, print the barcode sheet, and affix the labels near your packing station. Scanning O-CMD-VALIDATE tells Odoo to finalize the transfer hands-free.

Is this module compatible with Odoo.sh?

Yes, 100%. The code follows official Odoo ORM standards with no OS-level dependencies, making deployment on Odoo.sh effortless.
